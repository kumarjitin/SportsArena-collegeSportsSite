Sports Arena – College Sports Website
Sports Arena is a college sports website developed as a first-year web development project using HTML, CSS, and JavaScript. The website provides a platform for college students to explore sports activities, stay updated with college sports events, and learn more about different sports.

About the Project
The main objective of this project is to create an attractive and user-friendly website dedicated to college sports. It brings sports-related information together in one place and provides students with an engaging online experience.
This project was developed to practice and demonstrate fundamental front-end web development skills.

Features
Attractive and user-friendly interface
Information about different sports
College sports-related content
Responsive website design (if implemented)
Styled layouts using CSS
Interactive elements using JavaScript
Dedicated sports-themed sections

Technologies Used
HTML5 – Structure and content of the website
CSS3 – Styling, layouts, colors, and design
JavaScript – Interactive functionality and dynamic elements
